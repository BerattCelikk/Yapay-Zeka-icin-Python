Bu depo, yapay zeka ve veri bilimi süreçlerinde kullanılan temel Python konseptlerini, kütüphanelerini ve kendi çalışma notlarımı barındırmaktadır.

---

## 🗂️ Depo İçeriği

Depo, temelden ileri seviyeye doğru ilerleyen 12 modülden ve kendi eklediğim bir notlar dosyasından oluşuyor:

### 1️⃣ `1_python_giris`
Python'a giriş — yorum satırları, `print`, `input`, temel sözdizimi.

### 2️⃣ `2_python_temel_yapilar`
Değişkenler, veri tipleri (str, int, float, bool) ve temel veri yapıları (liste, tuple, dict, set).

### 3️⃣ `3_donguler_kontrol_yapilari`
`if / elif / else` şartlı ifadeleri, `for` ve `while` döngüleri.

### 4️⃣ `4_fonksiyonlar`
Fonksiyon tanımlama, parametreler, varsayılan değerler, `*args` / `**kwargs`, `return` kullanımı.

### 5️⃣ `5_dosya_islemleri`
`with open()` ile dosya okuma, yazma ve satır ekleme (append) işlemleri.

### 6️⃣ `6_hata_yonetimi`
`try / except / finally` blokları, özel (custom) exception sınıfları ile güvenli kodlama.

### 7️⃣ `7_ortam_paket_yonetimi`
Sanal ortam (`venv`) oluşturma, `pip` ile kütüphane kurulumu, `requirements.txt` yönetimi.

### 8️⃣ `8_numpy`
NumPy dizileri, temel istatistiksel işlemler (ortalama, standart sapma), matris işlemleri.

### 9️⃣ `9_pandas`
`DataFrame` oluşturma, filtreleme, gruplama ve temel veri manipülasyonu.

### 🔟 `10_matplotlib`
Çizgi grafikleri, eksen etiketleme ve temel veri görselleştirme teknikleri.

### 1️⃣1️⃣ `11_oop`
Nesne yönelimli programlama — sınıflar, `__init__`, metodlar, kalıtım (inheritance).

### 1️⃣2️⃣ `12_ogrenci_not_analiz_projesi`
Önceki tüm konuları birleştiren, öğrenci notlarını analiz eden mini kapanış projesi.

### 📄 `notlarim.md`
Yukarıdaki her modülü işlerken kendi yazdığım, çalıştırılabilir ek script örneklerini topladığım kişisel notlar dosyası — otomasyon ve AI agent temalı örnekler içeriyor.

## 🚀 Çalışma Yaklaşımı

Buradaki çalışmalar, teorik bilginin pratik uygulamalara (veri ön işleme, algoritma tasarımı vb.) dönüştürülmesi amacıyla hazırlanmıştır. Konular, gerçek dünyadaki veri setleri ve otonom sistem mimarileri göz önünde bulundurularak işlenmektedir.

## ⚙️ Kurulum

```bash
# Depoyu klonla
git clone https://github.com/BerattCelikk/Yapay-Zeka-icin-Python.git
cd Yapay-Zeka-icin-Python

# Sanal ortam oluştur
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate

# Gerekli kütüphaneleri kur
pip install numpy pandas matplotlib scikit-learn
```
